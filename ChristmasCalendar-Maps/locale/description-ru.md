# Рождество крестоносца: карты

21 сценарная карта рождественского календаря Krarilotus для Stronghold Crusader Extreme. Каждая карта появляется в **Редактор карт → Загрузить карту** начиная со своего дня (Door01 1 декабря, до Door21 21 декабря).

Включите **A Crusader's Christmas**, чтобы играть карты как календарь, с его тропой, страницами дверей и настройками. Сам по себе этот плагин только показывает карты в списке.
