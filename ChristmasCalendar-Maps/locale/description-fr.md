# Le Noël du croisé : cartes

Les 21 cartes scénario du calendrier de l'Avent de Krarilotus pour Stronghold Crusader Extreme. Chaque carte apparaît sous **Scénarios personnalisés → Charger une carte** à partir de son jour (Door01 le 1er décembre, jusqu'à Door21 le 21 décembre).

Active **A Crusader's Christmas** pour jouer les cartes en calendrier, avec son parcours, ses pages de portes et ses réglages. Seul, ce plugin ne fait que lister les cartes.
