# A keresztes karácsonya: pályák

Krarilotus adventi naptárának 21 forgatókönyv-pályája a Stronghold Crusader Extreme-hez. Minden pálya a maga napjától jelenik meg az **Egyéni forgatókönyvek → Térkép betöltése** alatt (Door01 december 1-jén, Door21 december 21-én).

Kapcsold be az **A Crusader's Christmas**-t, hogy naptárként játszd a pályákat, a hadjáratával, az ajtóoldalaival és a beállításaival. Önmagában ez a plugin csak felsorolja a pályákat.
