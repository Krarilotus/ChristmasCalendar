# Weihnachtskreuzzug: Einstellungen

Die Einstellungen, mit denen der Weihnachtskalender von Krarilotus gespielt wird: der Kalender als Extremkreuzzug von Custom Skirmish Trails, die Startwaren, die Korrekturen für Mauern, Belagerungsgeräte und Gebäude, die Tastenkürzel, der Zoom und die Oberflächenoptionen von UCP2 Legacy.

Die Schwierigkeitsgrade von **Weihnachtskreuzzug (A Crusader's Christmas)** aktivieren dieses Plugin.
