# La Navidad del cruzado: ajustes

Los ajustes con los que se juega el calendario de Adviento de Krarilotus: el calendario como ruta Extreme de Custom Skirmish Trails, los bienes iniciales, las correcciones de murallas, máquinas de asedio y edificios, los atajos de teclado, el zoom y las opciones de interfaz de UCP2 Legacy.

Las dificultades de **A Crusader's Christmas** activan este plugin.
