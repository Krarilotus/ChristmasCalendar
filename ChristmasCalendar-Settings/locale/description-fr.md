# Le Noël du croisé : réglages

Les réglages avec lesquels se joue le calendrier de l'Avent de Krarilotus : le calendrier comme parcours Extreme de Custom Skirmish Trails, les marchandises de départ, les correctifs des murs, des engins de siège et des bâtiments, les raccourcis clavier, le zoom et les options d'interface d'UCP2 Legacy.

Les difficultés de **A Crusader's Christmas** activent ce plugin.
