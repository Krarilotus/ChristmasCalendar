# Рождество крестоносца: ИИ

ИИ-лорды рождественского календаря Krarilotus: все 16 лордов со своими AIC, силой лорда и стартовыми войсками, настроенные под AIC Tactics. Этот плагин выбирает в AI Swapper сложный ИИ для каждого лорда вместе с настройками ИИ календаря для UCP2 Legacy и AIC Tactics.

ИИ есть и в силе Обычная и Сюжетная. Их выбирают сложности **A Crusader's Christmas**.

Сам по себе этот плагин даёт ИИ-лордов календаря сражениям и сетевым играм.
