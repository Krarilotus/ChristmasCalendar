# Рождество крестоносца: баланс

Баланс рождественского календаря Krarilotus: исходная игра с исправлениями ошибок из UCP2 Legacy и несколькими небольшими изменениями.

- Кузница стоит 100 золотых вместо 200.
- У рыцарей 25000 здоровья вместо 20000, как у мечников.
- Арабские мечники гибнут после 7 попаданий из арбалета вместо 3.
- Копейщики гибнут после 5 попаданий стрел вместо 3 и выдерживают одно попадание из арбалета; они бегают, а не ходят.
- Осадные рабочие гибнут после 12 попаданий стрел вместо 5 и после 5 попаданий из арбалета или пращи вместо 2; они стоят 20 золотых вместо 4.
- Торговый пост бесплатный.
- Арабские мечники рушат стены примерно вдвое быстрее, а знахарь лечит раненых.

Значения взяты из Rebalancer (`resources/balance/calendar.json`), Running Units и UCP2 Legacy. Сам по себе этот плагин даёт баланс календаря сражениям и сетевым играм.
